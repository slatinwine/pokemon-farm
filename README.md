# 🌱 宝可梦农场 · 百变怪的农庄

一个零依赖、单文件的宝可梦主题 2.5D 农场模拟游戏。基于 Three.js 低多边形渲染，
全部音效由 WebAudio 实时合成，无需任何素材文件 —— 打开即玩。

## 快速开始

**无需安装**：直接用浏览器打开 `pokemon-farm.html` 即可（Three.js 从 CDN 加载，需要联网）。

- 也可以部署到任意静态托管（GitHub Pages / Vercel / Nginx）。

## 玩法

开垦草地 → 种植树果 → 浇水 → 睡觉过天 → 收获 → 卖给喵喵杂货摊换金币。

- **四季系统** 🌸☀️🍁❄️：28 天一季，换季会枯萎不合季节的作物，冬季只有雪绒果能存活
- **天气**：雨天自动浇水；冬季降雪
- **钓鱼**：池塘甩竿，咬钩瞬间收竿；稀有度三档（鲤鱼王 / 角金鱼 / 暴鲤龙）
- **宝可梦伙伴**：皮卡丘、伊布、小火龙在农场漫步；野生宝可梦每天出没，
  聊天/喂食提升好感，满 100 结为挚友后百变怪可变身成它并获得被动加成
- **技能研习**：电光一闪（冲刺）、求雨圈（3×3 浇灌）、日光束（催熟）、悠闲垂钓等
- **成长目标**：新手引导清单 + 8 个里程碑成就

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| 空格 / 鼠标左键 | 使用选中物品 |
| E / 鼠标右键 | 互动（对话 / 进门 / 商店 / 收获） |
| 1~9 / 滚轮 | 选择快捷栏物品 |
| Q / R | 循环切换物品 |
| T | 切换变身形态（需已结交挚友） |
| F | 日光束（需已研习） |
| Shift | 冲刺（需已研习电光一闪） |
| Esc | 菜单（存档 / 读档 / 导出存档码） |

触屏设备会自动显示虚拟方向键与「使用 / 互动」按钮。

进度自动保存在浏览器 localStorage，菜单里可导出存档码跨浏览器迁移。

## 技术要点

- **单文件架构**：HTML + CSS + JS 一体，模拟逻辑与 3D 渲染解耦
- **渲染**：Three.js r149，正交 2.5D 视角，地面用 InstancedMesh 单 draw call，
  静态材质统一缓存；昼夜光照、季节天空色、天气粒子全程序化生成
- **音频**：WebAudio 合成引擎 —— 分层音效（噪声打击乐 + 琶音），
  环境音随昼夜/天气切换（鸟鸣 / 蟋蟀 / 雨声）
- **健壮性**：存档版本迁移、读档失败兜底新档、WebGL 上下文丢失提示、
  触屏/键鼠自适应

## 开发

游戏为单文件，直接修改 `pokemon-farm.html` 后刷新浏览器即可。

回归测试：在浏览器地址栏打开 `pokemon-farm.html#selftest`，游戏会内置运行
15 项核心逻辑断言（新档、移动、耕种收获出售全流程、换季、存读档往返），
测完自动还原你的真实存档。
